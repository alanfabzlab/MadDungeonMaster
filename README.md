# Mad Dungeon Master 👹

A text-based interactive C# boss-script generator built as a Checkpoint Project.

## 📌 Features
- Captures multiple encounter inputs (boss name, dark deed, adjective, hero weapon, dungeon, time of day).
- Dynamically structures a villain monologue for a boss fight.
- Uses C# logical (`&&`, `||`) and comparison (`==`, `!=`) operators to alter the closing lines.
- Controlled via a primary `while` loop allowing continuous encounter generation.

## 🛠️ Requirements & Tech Stack
- .NET / C#
- Visual Studio Code

## 🚀 How to Run
```bash
dotnet run
```
